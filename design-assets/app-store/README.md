# 앱인토스 출시용 디자인 자산 (초안)

코드로 생성한 초안입니다. 실제 출시 전에는 디자이너 검수를 권장합니다.

## 파일

| 파일 | 용도 | 크기 |
| --- | --- | --- |
| `icon-light-600.png` | 앱 로고 (라이트) | 600×600 |
| `icon-dark-600.png` | 앱 로고 (다크모드) | 600×600 |
| `thumbnail-1932x828.png` | 썸네일 | 1932×828 |

디자인 컨셉: 앱 내 브랜드 마크("ㄱㄴㄷ" 배지)와 동일하게, 3x3 그리드에 자모 ㄱ·ㄴ·ㄷ를
대각선으로 배치해 "한글 자모 수도쿠"를 상징화했습니다. 폰트 렌더링에 좌우되지 않도록
자모는 텍스트가 아니라 SVG 선으로 직접 그렸습니다.

## 앱 검색 키워드 (안)

우선순위 순:

1. 한글 자모 수도쿠
2. 자모 수도쿠
3. 한글 수도쿠
4. 수도쿠
5. 스도쿠
6. 한글 게임
7. 자음 게임
8. 초성 게임
9. 퍼즐 게임
10. 두뇌 게임
11. 두뇌 트레이닝
12. 로직 게임
13. 한글 학습 게임
14. 캐주얼 게임
15. 무료 퍼즐 게임

`한글 자모 수도쿠`/`자모 수도쿠`처럼 앱을 정확히 지칭하는 키워드와, `수도쿠`/`퍼즐 게임`/
`두뇌 게임`처럼 카테고리 전체 검색에 걸리는 키워드, `한글 게임`/`자음 게임`/`초성 게임`/
`한글 학습 게임`처럼 "숫자 대신 한글 자모"라는 이 앱만의 차별점을 노리는 키워드를 섞었습니다.
실제 등록 가능한 키워드 개수·형식은 앱인토스 콘솔의 앱 등록 화면에서 확인해 맞춰주세요.

## 출시 전 확인 필요

- [ ] 그래픽 디자이너 검수 (브랜드 가이드가 있다면 반영)
- [ ] 앱인토스 콘솔이 요구하는 정확한 포맷(PNG 여부, 투명배경 허용 여부, 코너 반경 처리 등) 재확인
- [ ] 실제 앱 카테고리(게임) 등록 화면에서 키워드 개수 제한 확인 후 위 목록에서 선택/조정
